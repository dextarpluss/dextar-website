## 8. SOBRE A DEXTAR
# Tecnologia com propósito operacional.
A história da Dextar começa a partir de uma necessidade concreta de automação logística identificada em um projeto iniciado em **2010**.

Naquele contexto surgiu a oportunidade de desenvolver automação para controle logístico por radiofrequência, criando uma base para que a operação pudesse posteriormente evoluir para uma gestão mais estruturada de armazém.

O projeto aproximou conhecimento de **implantação de ERP, processos empresariais, logística e desenvolvimento de automações**. Essa combinação orienta a forma como a Dextar entende tecnologia: ferramenta para resolver problemas reais da operação.
