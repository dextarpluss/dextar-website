# Dextar++ Website Handoff & Implementação (v1.0)

Este diretório contém a documentação completa de handoff e a implementação técnica oficial do website da **Dextar Soluções em Tecnologia (Dextar++)**.

## 🚀 Código-Fonte do Website
A aplicação foi construída em Next.js 16 (App Router) com TypeScript e CSS Modules na pasta [`website/`](file:///c:/Users/Marcelo/OneDrive/Smart%20Corporation/DextarTecnologia/Identidade%20Visual/DEXTAR_SITE_HANDOFF_FINAL_v1.0/website).

### Para executar localmente:
```bash
cd website
npm install
npm run dev
```

### Para testar o build estático (SSG):
```bash
cd website
npm run build
```

## 📁 Estrutura do Pacote Handoff
1. `00_LEIA_PRIMEIRO.md` — Ordem de leitura e regras de precedência.
2. `01_BRAND/` — Identidade visual, manual da marca e logos oficiais.
3. `02_CONTENT/` — Matriz de textos oficiais (`DEXTAR_WEBSITE_CONTENT_v1.0.md`).
4. `03_DESIGN_SYSTEM/` — Guia de tokens e componentes (`DEXTAR_DIGITAL_DESIGN_SYSTEM_v1.0.md`).
5. `04_WIREFRAMES/` — Referências visuais conceituais.
6. `05_IMPLEMENTATION/` — Especificação técnica e checklist de homologação.
7. `website/` — Aplicação Next.js completa pronta para produção.
